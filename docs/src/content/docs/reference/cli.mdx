---
title: CLI arguments
description: Command-line options accepted when Lucent starts.
---

Pass command-line arguments to the Lucent executable to configure app behaviors as soon as possible.

```sh
Lucent [options]
```

## Options

| Argument        | Value                       | Description                                                                                                                                 |
| --------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `--launch-mode` | `game` or `account-manager` | Opens the selected window at startup instead of the saved launch preference. `manager` is also accepted as shorthand for `account-manager`. |

## Examples

Open the account manager:

```sh
Lucent --launch-mode account-manager
```

On macOS, pass arguments to an installed application with `open`:

```sh
open -a Lucent --args --launch-mode account-manager
```

:::tip[Compatibility aliases]
The camel-case alias `--launchMode` is also accepted. Prefer `--launch-mode`
in new commands.
:::
