:::note
As of v0.1.0-beta.1, Lucent runs on a
[patched version of Ruffle Web](https://github.com/toommyliu/ruffle/tree/e86a3fba0cfd80175a3538d6a81917c701e6bd45).
It requires macOS 13 (Ventura) or later, or Windows 10 or later. On Linux, use a
distribution release that is still supported by its maintainer.
:::

## Download Lucent

Download the latest version for your system from the
[releases page][latest-release].

## Update Lucent

Lucent can tell you when a new release is available, but it cannot install it.
Updates must be downloaded manually.

Read the [changelog](/changelog) to see what changed.

[latest-release]: https://github.com/toommyliu/lucent/releases/latest#assets
