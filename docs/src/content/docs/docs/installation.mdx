## Download Lucent

Get the build for your system from the [download page](/download). It lists
the system requirements and which file to pick for each platform.

## Update Lucent

Lucent can tell you when a new release is available, but it cannot install it.
Updates must be downloaded manually.

Read the [changelog](/changelog) to see what changed.
